# جدولة الامتحانات بالخوارزميات الذكية (GA – PSO – ACO)

مشروع مقرر **الخوارزميات الذكية**. نحل مسألة جدولة الامتحانات بثلاث خوارزميات من المقرر:

- الخوارزمية الجينية **GA** (الفصل الثالث)
- أمثلة سرب الجسيمات **PSO** (الفصل الرابع)
- مستعمرة النمل **ACO** (الفصل الخامس)

ونقارن بينها وبين البحث العشوائي (Random Search)، الذي يمثّل خط الأساس (Baseline).

## المتطلبات

- Python 3.9 أو أحدث
- `pip install -r requirements.txt` (المكتبات المطلوبة: numpy و matplotlib)

## طريقة التشغيل

```bash
# 1) توليد البيانات (Small / Medium / Large). البيانات موجودة أصلاً في data/، وهذه الخطوة تعيد توليدها بنفس الشكل بالضبط
python data/generate_data.py

# 2) التجربة الرئيسية: 4 خوارزميات × 3 أحجام × 10 تشغيلات (حوالي 12 دقيقة على نواتين)
python run_experiments.py

#    تجربة سريعة للتأكد أن كل شيء يعمل (أقل من دقيقة)
python run_experiments.py --runs 2 --sizes small

# 3) تجربة "نفس الزمن": GA و PSO يأخذان نفس زمن ACO (حوالي 12 دقيقة)
python equal_time.py --runs 5

# 4) اختبار حساسية الـ Hyperparameters على Medium (حوالي 4 دقائق)
python tune.py
```

كل التشغيلات تستخدم seeds ثابتة، لذلك تتكرر النتائج نفسها (جودة الحلول). أما أزمنة التنفيذ فتختلف حسب الجهاز.

## هيكل المشروع

```
data/
  generate_data.py      توليد المسائل الثلاث (seed ثابت)
  small|medium|large/   exams.csv, enrollments.csv, config.json
src/
  problem.py            تمثيل الحل + دالة الهدف (القيود الصلبة والمرنة)
  common.py             تتبع أفضل حل ومنحنى التقارب
  random_search.py      Baseline (randomoptimize من الفصل 3)
  ga.py                 الخوارزمية الجينية
  pso.py                سرب الجسيمات
  aco.py                مستعمرة النمل
run_experiments.py      التجارب + الجداول + الرسوم
equal_time.py           مقارنة بنفس الزمن
tune.py                 اختبار الـ Hyperparameters
results/                النتائج (csv و png والجداول الناتجة)
```

## المسألة باختصار

- **الحل:** مصفوفة `s` طولها عدد الامتحانات، و`s[i]` هو رقم الفترة الزمنية للامتحان `i` (Value Encoding).
- **القيود الصلبة:** لا يوجد طالب عنده امتحانان في نفس الفترة، ولا يتجاوز عدد الطلاب في أي فترة عدد المقاعد.
- **القيود المرنة:** امتحانان متتاليان في نفس اليوم (وزن 3)، وامتحانان في نفس اليوم (وزن 1).
- **دالة الهدف (للتصغير):** `cost = 1000 × (مخالفات صلبة) + (عقوبات مرنة)`.
